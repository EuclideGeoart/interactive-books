## What changed when the machine learned?

Start with the selected observation at $x=0$, whose target is $y=1$. The initial rule predicts $0$. Change the bias to $1$: its prediction becomes $1$. Every other prediction shifts by the same amount. Change the weight instead: predictions change in proportion to their inputs. You are editing two numbers in a family of rules.

A learning algorithm chooses those numbers using examples and a criterion. Here the family is the affine predictor

$
f_\theta(x)=wx+b,\qquad
\theta=\begin{bmatrix}w\\b\end{bmatrix}.
$

The model is this parameterized mapping. Its parameters are $w$ and $b$. The data are observed input–target pairs $(x_i,y_i)$. The algorithm evaluates candidate parameters using a loss, then returns a new parameter vector. Learning need not discover a symbolic law or remember each example; in this experiment, five rows influence two shared coefficients.

The input and target have different jobs. An input is information available when a prediction must be made. A target is the observed quantity the prediction is supposed to match. Targets must not quietly become input features when they would be unavailable at prediction time.

## Trace the complete mechanism

For a supervised training batch, the pipeline is:

1. Observe inputs and targets with stable sample identities.
2. Represent inputs as compatible numerical features.
3. Apply the current predictor.
4. Compare predictions with targets and aggregate the error.
5. Use that error to choose changed parameters.

The sheet stores scalar features in a batch $X$ of shape $5\times1$. Each sample occupies a row; a single sample's feature vector is a $1\times1$ column. The weight matrix is $1\times1$, the target column is $5\times1$, and bias broadcasts separately. A column convention does not mean that every batch must have only one row.

Define $r_i=wx_i+b-y_i$ and the mean squared error

$
L(w,b)=\frac1n\sum_{i=1}^n r_i^2.
$

Differentiation gives $dw=(2/n)\sum_i r_ix_i$ and $db=(2/n)\sum_i r_i$. The weight gradient contains $x_i$ because the sensitivity of a prediction to $w$ is $x_i$. Both partial derivatives are calculated before either parameter changes. The algorithm then returns $w-\eta dw$ and $b-\eta db$, where the user chooses the positive learning rate $\eta$.

The selected row is a microscope, not a switch to one-row training. The loss and update still use all five observations. A selected sample with $x=0$ contributes nothing directly to $dw$, although its target can change $db$.

## Work through the first learned rule

The five inputs are $[-2,-1,0,1,2]$ and targets are $[-3,-1,1,3,4]$. These are explicit hand-authored toy values, with no units or claim about a real population. At $w=0.5,b=0$, predictions are $[-1,-0.5,0,0.5,1]$ and residuals are $[2,0.5,-1,-2.5,-3]$.

The squared errors sum to $20.5$, so $L=4.1$. The residual sum is $-4$ and the residual-times-input sum is $-13$. Consequently $dw=-5.2$ and $db=-1.6$. At $\eta=0.1$,

$
w_{\mathrm{next}}=0.5-0.1(-5.2)=1.02,\qquad
b_{\mathrm{next}}=0-0.1(-1.6)=0.16.
$

The selected input $0$ now predicts $0.16$, with residual $-0.84$. Across the batch the new squared errors sum to $8.532$, giving MSE $1.7064$. The update improves this criterion on these observations. It does not establish performance on future data.

## Inference uses the returned parameters

Reset and choose inference. For query $x=1.5$, the original parameters predict $0.75$. There is no observed query target, so an observed residual and query loss are undefined. The sheet displays that reason and disables the supervised update.

After training once, the same query predicts $1.02(1.5)+0.16=1.69$. No additional learning is required to evaluate the mapping. A later measured target could be used to evaluate it; deciding to retrain is a separate operation.

Substituting zero would invent an observation and change the supervised problem. Inference can produce a prediction without claiming to know its error.
</Callout>

## Limits and common mistakes

This sheet supports weights and biases in $[-4,4]$, observations and queries in $[-5,5]$, and rates from $0.001$ to $1$. An unsupported update is rejected with the previous valid state retained. A permitted rate does not guarantee decreasing loss.

Numbers use binary64 arithmetic. Given coordinates retain round-trip decimal text; computed results carry an approximation sign. Display rounding never feeds training. Constant inputs and one-sample data can support prediction without identifying a unique weight and bias. This example neither proves causation nor justifies extrapolation.

Generalization needs an evaluation design, introduced in <a href={href('/chapters/training-validation-testing/')}>training, validation and testing</a>. More elaborate models change the feature representation or parameter family while preserving the distinction between observations, predictions, objectives and decisions.
