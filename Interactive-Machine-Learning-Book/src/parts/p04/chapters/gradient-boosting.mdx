## An ordered additive model

In this lesson, boosting is squared-error regression:

$$
F_0(x)=\bar y,\qquad
F_m(x)=F_{m-1}(x)+\eta h_m(x),\quad 0<\eta\le1.
$$

Each hm is a new regression tree. Its training targets depend on Fm−1, so stage order matters. Bagging uses resamples of the original targets and averages separately fitted models; this boosting procedure uses all original rows and accumulates learning-rate-scaled corrections.

The experiment is deterministic all-feature squared-error boosting. It does not add bootstrap sampling, random feature subsets or a classification variant. Many other boosting algorithms use other objectives, gradients, line searches or weighting schemes. Only the mechanism derived here is claimed.

## Derive the residual target from the loss

For a single row, choose half squared error:

$$
\ell_i(F_i)=\frac12(y_i-F_i)^2,\qquad
-\frac{\partial\ell_i}{\partial F_i}=y_i-F_i.
$$

The negative per-example gradient is exactly the residual ri=yi−Fi. The training objective is L=(1/n)sum elli=half MSE. Its vector gradient has entries (Fi−yi)/n; using residuals as the fitted direction absorbs this common positive scaling into the step convention.

Fit hm to these residual targets by minimizing squared error within a bounded regression-tree family. Its leaves predict residual means. Then update all predictions simultaneously using the old Fi and this new hm. A residual vector, fitted correction vector and prediction vector are conceptual n by 1 columns; X remains n by 2. There is no coefficient matrix or softmax dimension hidden in this experiment.

## Why the rate controls the correction

Write r for the old residual vector and h for the new fitted leaf-mean vector. The new residual is r−ηh, giving

$$
L(F+\eta h)-L(F)
=-\frac{\eta}{n}r^\mathsf T h+\frac{\eta^2}{2n}h^\mathsf T h.
$$

Within each fitted leaf, h is its residual mean, so the leaf's residual sum equals its count times h. Summing leaves gives r transpose h = h transpose h. Consequently

$$
L(F+\eta h)-L(F)=
-\frac{\eta(2-\eta)}{2n}\|h\|^2.
$$

For $0<\eta\le1$ this is nonpositive in exact arithmetic. A zero correction leaves the objective unchanged. This argument applies to least-squares leaf means on the current rows; it is not a universal guarantee for arbitrary objectives or different stage solvers. Lower training loss also does not imply better validation performance.

## Make the weak learner's limits visible

Set **Maximum depth** to 0. The mean-initialized residuals sum to zero, so a root-only residual tree predicts zero and cannot change the original mean. Increase depth to 1 and observe a real correction. Set constant features while retaining varying targets: no separating test exists, and again the residual mean is zero. Constant targets are already solved by the baseline.

Empty data have no baseline, residual stages or loss. Invalid numeric edits preserve the last accepted state. The pure kernels reject nonfinite inputs and nonfinite residual squares or sums. Python observations are normalized to binary64 consistently with the browser, and seed/count/depth arguments remain integer indices after validation.

The sheet permits rates 0.01…1, up to six stages and depth five; the pure boosting kernel allows every finite rate in (0,1]. The practical number of stages, depth and rate should be selected with validation. Repeated small corrections can overfit despite a monotone training objective.

## Connections and independent proof

For logistic BCE, the negative derivative with respect to a logit is y−sigmoid(z), not the scalar-regression residual y−z. Other losses have their own derivatives and may require different terminal-value optimization. This lesson implements none of those variants; III-13 supplies the distinct logistic derivation.

The independent tiny-stage oracle retains Fraction means, residuals, updates and losses throughout, while a separate exhaustive partition search chooses each residual tree.
