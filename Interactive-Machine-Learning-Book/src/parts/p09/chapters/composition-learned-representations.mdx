## Composition changes the coordinates supplied to the next layer

For a single sample, define

$$
z_1=W_1x+b_1,\qquad a_1=\phi(z_1),\qquad z_2=W_2a_1+b_2.
$$

Activation applies separately to each hidden coordinate. The final output is z2; there is no output activation or classification threshold. The first layer can be understood as h copies of the neuron from <a href={href('/chapters/linear-model-artificial-neuron/')}>III-40</a>. Each row of W1 contains one hidden neuron's weights. Its activated result becomes one coordinate of the next layer's input.

The contracts are x d×1, W1 h×d, b1,z1,a1 h×1, W2 o×h, and b2,z2 o×1. Inner dimensions determine which products exist. Bias vectors must match the corresponding number of rows; they are not arbitrary broadcastable objects. The explorer fixes d=h=2,o=1. The pure model supports other positive compatible dimensions and rejects incompatible, empty or ragged shapes. It supports no batches; columns are flat arrays in JSON, not observation rows.

A **representation** here simply means the coordinates a1 supplied to the second layer. A **learned representation** would require those coordinates' defining parameters to have been fitted from data. Their interpretation depends on the objective and evidence, not the word “hidden.” Our hand-chosen features do not demonstrate semantic understanding, learned categories or generalization.

## Prove that two affine maps collapse

For identity activation a1=z1. Substitution and distributivity yield

$$
z_2=W_2(W_1x+b_1)+b_2
=(W_2W_1)x+(W_2b_1+b_2).
$$

Thus W_eff=W2W1 has shape o×d and b_eff=W2b1+b2 has shape o×1. No matter how wide the intermediate layer is, the resulting input-to-output function is affine. Repeating the argument collapses further affine-only layers too. Such factorizations may impose rank constraints or change optimization, but they do not add a new nonlinear input-output function family.

With nonidentity φ, replacing a1 by z1 changes the function in general. The comparison in the explorer explicitly removes φ: it is a **counterfactual affine collapse**, not an asserted equivalent representation of the nonlinear network. They may agree at some inputs, and some special parameters make them agree everywhere. One equality or inequality at a single input should not be mistaken for a universal proof.

## Work an identity composition completely

Consider the independent literal example

$$
x=\begin{bmatrix}2\\-1\end{bmatrix},\quad
W_1=\begin{bmatrix}1&2\\-1&0.5\end{bmatrix},\quad
b_1=\begin{bmatrix}1\\-2\end{bmatrix},\quad
W_2=\begin{bmatrix}3&-2\end{bmatrix},\quad b_2=0.5.
$$

Hidden row 1 has products (2,−2), dot 0, and z1[1]=1. Hidden row 2 has products (−2,−0.5), dot −2.5, and z1[2]=−4.5. With identity, the output products are (3,9); the running sums are 3 then 12 and z2=12.5.

The effective weight row is (3·1+(−2)(−1),3·2+(−2)0.5)=(5,5). Its bias is 3·1+(−2)(−2)+0.5=7.5. Direct collapse gives 5·2+5(−1)+7.5=12.5. All these numbers are exactly representable dyadic values. Enter these parameters in the explorer to reproduce each intermediate.

Switch to ReLU without changing them. The hidden coordinates become (1,0) and z2=3.5. The counterfactual remains 12.5. The difference −9 comes from replacing the negative hidden coordinate by zero, before applying its second-layer weight −2. Applying ReLU only after the final sum would be a different network.

## Construct XOR with two hand-chosen features

The opening parameters are

$$
W_1=\begin{bmatrix}1&-1\\-1&1\end{bmatrix},\quad b_1=\begin{bmatrix}0\\0\end{bmatrix},\quad
W_2=\begin{bmatrix}1&1\end{bmatrix},\quad b_2=0.
$$

They define h1=max(0,x1−x2), h2=max(0,x2−x1), and z2=h1+h2=|x1−x2|. On binary inputs this equals XOR. Outside the four binary corners it is an absolute-difference function, not a guaranteed binary output or probability.

Now independently rule out a scalar affine function that matches these four values. Suppose f(x)=c1x1+c2x2+b. The (0,0) case forces b=0. The (1,0) and (0,1) cases force c1=c2=1. Then f(1,1)=2, contradicting the required 0. This contradiction does not rely on the implementation, or on merely observing the collapse in the browser. It concerns exact scalar outputs; it does not sneak in a thresholding rule.

For these matrices W_eff=(0,0) and b_eff=0. Identity composition therefore outputs zero for every input, while ReLU separates the two signs of a difference. We chose the features using our knowledge of XOR. The example establishes representational possibility, not that a trainer discovers those parameters or that the coordinates have learned a semantic concept.

## Arithmetic order is part of the experiment

The affine-collapse proof is exact algebra over the reals. Binary64 rounds each product and addition. A scalar example makes the limit visible: choose x=1, W1=1, b1=10¹⁶, W2=1, b2=−10¹⁶ and identity. The staged calculation rounds 1+10¹⁶ to 10¹⁶, then cancels to 0. The collapsed bias cancels to 0 first, and the direct affine output is 1. Algebraic equivalence does not promise identical rounded intermediates. These scales exceed the UI's ±1000 editing bound but are covered by the authored pure-model tests.

All active forward products, sums and bias additions must be finite, and nonzero affine products may not underflow to zero. Computing W_eff can overflow even when ReLU makes the actual hidden values zero. In that case the comparison is explicitly unavailable and the valid forward result remains visible. No fabricated effective weights, automatic rescaling or tolerance-based clipping is applied. Sigmoid uses stable signed branches and discloses rounded endpoint tails.
</Callout>

The oracle uses exact Fraction sums for these small rational examples, with Decimal activation values for sigmoid. Exact integer/dyadic fixtures are checked exactly; transcendental quantities use the documented 32ε small-case allowance from III-40, with relative-only checks for small nonzero tails. There is no arbitrary tolerance for shape acceptance, XOR targets or the contradiction. Near cancellation, input precision and intermediate rounding can dominate; no small universal relative error guarantee is implied.

## Mistakes, connections and the next book

More affine-only layers do not create nonlinear expressiveness. More hidden coordinates do not prove that useful features were learned. A hidden activation is not the same as an output threshold. ReLU at zero is a valid forward value even though derivative-based learning needs a convention at the corner. A sigmoid hidden feature can saturate; a tiny forward sensitivity matters later to derivatives, not to the shape of matrix multiplication.

Book III has distinguished model families, fitting objectives, evaluation and numerical limits. Book IV must connect a forward output to a task-specific loss, use the chain rule to relate changes in that loss to earlier weights, and use optimization to update parameters. Book II's actual chain-rule, gradient and objective prerequisites are linked below through the frozen resolver. Training-only data boundaries, held-out evaluation and numerical diagnostics remain necessary when features are learned. This closing chapter implements no derivatives, backward pass, trainer or later architecture.
