## Change one class score and inspect all probabilities

Edit a weight-matrix cell in the opening sheet. Each row of logits is normalized across classes, so increasing one class score changes every class probability in that sample. Press Apply one update and inspect the gradient and prospective next matrix before replaying three updates.

Set **Common logit shift** to $1000$. The logits change, but the probabilities, cross entropy and gradient stay the same up to binary64 rounding. The mechanism subtracts a row maximum before exponentiating. Reset restores the original hand-authored three-class batch and weights.

## Define class columns and one-hot targets

With $n$ samples, $d$ augmented features and $k$ mutually exclusive classes,

$$
X\in\mathbb R^{n\times d},\quad W\in\mathbb R^{d\times k},\quad Z=XW\in\mathbb R^{n\times k}.
$$

Each column of $W$ is one class's coefficient column; the intercept is the first feature row. The integer label column has shape $n\times1$. Its one-hot encoding $Y$ has shape $n\times k$: row $i$ has a one at class index $y_i$ and zeros elsewhere.

Softmax normalizes each logit row:

$$
P_{ic}=\frac{e^{Z_{ic}}}{\sum_j e^{Z_{ij}}},\qquad \sum_c P_{ic}=1.
$$

The class prediction is the largest probability, equivalently the largest logit. Here exact maximum ties choose the lowest class index, an explicit deterministic decision convention. These are mutually exclusive classes; independent binary sigmoids would answer a different multilabel problem.

## Derive stable cross entropy

For a row maximum $m_i=\max_c Z_{ic}$, factor out the common exponential:

$$
P_{ic}=\frac{e^{Z_{ic}-m_i}}{\sum_j e^{Z_{ij}-m_i}}.
$$

All shifted logits are nonpositive and at least one is zero, so the exponential sum lies between one and $k$. This avoids overflow. The class-index cross entropy can be calculated from shifted logits without taking a logarithm of a rounded probability:

$$
\ell_i=\log\sum_c e^{Z_{ic}-m_i}-(Z_{i,y_i}-m_i),\qquad L=\frac1n\sum_i\ell_i.
$$

Adding a common scalar to a logit row changes neither probabilities nor this loss. It does not make the score matrix uniquely identifiable; class probabilities depend on relative scores.

## Derive the gradient matrix

Differentiate the row log-sum-exp and subtract the selected class's logit. The result is

$$
\frac{\partial L}{\partial Z}=\frac1n(P-Y)\in\mathbb R^{n\times k},
\qquad \nabla_WL=\frac1nX^\mathsf T(P-Y)\in\mathbb R^{d\times k}.
$$

There is no MSE factor of two. The $1/n$ belongs exactly once in this mean-loss gradient. Summing each row of $P-Y$ gives zero; each feature row of the weight gradient therefore sums to zero up to rounding. This checks class normalization and the one-hot target representation.

Gradient descent updates the entire old-state matrix simultaneously: $W^+=W-\eta\nabla_WL$. The UI displays the gradient shape, each numeric row and the prospective next row. Replay frames contain actual detached weight matrices, not pictures of a changing bar chart.

## Extreme logits and common mistakes

For logits $[1000,0,-1000]$ and actual class two, probability for class two underflows to zero, yet stable cross entropy is approximately $2000$ and the logit gradient is approximately $[1,0,-1]$. Taking $-\log$ of a displayed zero probability would lose this finite logit-based calculation.

Do not normalize down the sample axis. Each sample needs its own probability distribution across classes. Do not multiply $X^\mathsf T$ by an integer label column; the gradient subtracts the one-hot matrix. Do not average twice. Do not mistake a common row shift for increased confidence; confidence changes with score differences.

## Numerical limits and connections

The pure kernel supports 1–64 rows, 1–7 features and 2–6 classes with finite inputs and valid integer labels. The sheet fixes three classes and three samples, lets you edit the feature, label and six weights, and bounds weights/shift to ±1000. Nonfinite logit differences, losses or updates are rejected with a reason. Underflow follows binary64; a displayed approximate zero does not rewrite the stored value.

Native controls support numeric, keyboard and touch edits; immutable replay follows the displayed weight matrix, and editing a historical frame ends replay. Independent 80-digit Decimal unshifted probabilities verify the stable results, and centered finite differences separately verify every gradient entry. The canonical Python `multiclass` uses explicit NumPy matrices and one-hot targets from scratch.

Softmax generalizes logistic probability modeling and leads toward the neuron/matrix composition chapters. You should be able to state all shapes, derive $P-Y$ and $X^\mathsf T(P-Y)/n$, explain shift invariance and retain finite loss when a wrong class probability underflows.
