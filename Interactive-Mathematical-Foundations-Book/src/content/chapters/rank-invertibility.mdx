## Intuition: count information, not entries

A matrix with two identical columns stores two lists but provides one direction. Two inputs can then produce the same output: transferring weight from one repeated column to the other changes the input without changing the result. Rank counts independent output directions, while nullity counts independent ways an input can disappear.

The shaded image is the image of a bounded input square. When rank is two, the full mathematical image is the entire plane; the displayed polygon is only a finite sample. At rank one it becomes a segment along the image line. At rank zero all inputs reach the origin.

## Definition

The rank of $A\in\R^{m\times n}$ is the dimension of its column space, equivalently its row space or its number of pivots. The null space is

$$
\ker A=\{z\in\R^n:Az=0\}.
$$

Its dimension is the nullity. Rank-nullity states

$$
\operatorname{rank}A+\dim\ker A=n.
$$

The domain dimension is the number of columns, not the number of rows.

## Derivation: each free column supplies a null direction

In reduced form, pivot variables can be expressed in terms of the free variables. Set one free variable to $1$ and the others to $0$; solve the pivot entries to obtain a null vector. Doing this for every free column produces an independent null-space basis. There are $n-r$ free columns when there are $r$ pivots, proving rank-nullity in this elimination setting.

A nonzero pivot row adds a constraint not implied by earlier rows. Zero rows are redundant. This also explains why independent rows and independent columns have the same count, even though the vectors live in different coordinate spaces.

## Worked examples

For $A=\begin{bmatrix}1&2\\2&4\end{bmatrix}$, the second column is twice the first. Elimination leaves one pivot; rank is $1$, nullity is $1$, and $z=(-2,1)$ satisfies $Az=0$. Any $x$ and $x+tz$ have the same image. Replay **Repeated columns** and reconstruct its displayed null direction by substitution.

For $A=\begin{bmatrix}0&1&2\\0&2&4\end{bmatrix}$, only the middle column has a pivot. Rank is $1$ and nullity is $2$, with basis $(1,0,0)$ and $(0,-2,1)$. The skipped first column and repeated third column explain the two missing directions in different ways.

The close preset has determinant $4(3.98)-(3.99)^2=-0.0001$. Its two columns are exactly independent even if the narrow image appears flat at screen resolution. Its inverse can be very sensitive to uncertain measurements; exact rank and numerical reliability answer different questions.

## Full rank and invertibility

For a square $n\times n$ matrix, full rank $n$ is equivalent to a trivial null space, independent columns and existence of a two-sided inverse. Every output is reachable and has exactly one input.

For a rectangular matrix, **full column rank** means injectivity: no two inputs share an output. **Full row rank** means surjectivity: every output is reachable. A 2×3 rank-two map is surjective but has a one-dimensional null space. A 3×2 rank-two map is injective but cannot reach every vector in $\R^3$. Neither has an ordinary two-sided inverse.

## Common mistakes

Rank is not the number of nonzero entries or columns. A nonzero column can be redundant. Rectangular full rank does not imply two-sided invertibility. A null vector lives in the input space. Row reduction preserves solution sets and rank but generally changes the pictured output-space basis.

## Numerical considerations

Exact zero decisions use rational arithmetic. Geometric pixels and rounded inspectors cannot certify dependence. Practical numerical rank uses a threshold tied to scale, uncertainty and the algorithm; one universal epsilon is inadequate. A nonzero determinant alone does not promise a well-conditioned solve.

## Engineering and ML connections

Rank identifies redundant features and unidentifiable parameter directions. Null spaces describe weights that change without altering predictions. Full column rank gives unique linear-model coefficients; rank deficiency leads directly to nonunique least-squares minimizers in II.18.
