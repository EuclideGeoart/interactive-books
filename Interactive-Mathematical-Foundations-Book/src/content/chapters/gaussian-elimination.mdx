## Intuition: replace difficult equations with equivalent ones

An equation is a constraint on an input. Swapping two constraints changes their order, not their intersection. Multiplying a constraint by a nonzero number rewrites the same statement. Adding a multiple of one equation to another can cancel a variable while retaining all the information needed to recover the original equations.

The augmentation bar is a reminder that the right-hand side belongs to the row. Watch it change during every operation; changing coefficients alone would describe a different system.

## Definition

For $A\in\R^{m\times n}$ and $b\in\R^m$, elimination rewrites the augmented matrix $[A\mid b]$ using three reversible operations:

1. $R_i\leftrightarrow R_j$.
2. $R_i\leftarrow cR_i$, with $c\ne0$.
3. $R_i\leftarrow R_i+cR_j$, with $i\ne j$.

A **pivot** is the first nonzero coefficient in a nonzero echelon row. Echelon pivots step strictly to the right, all entries below each pivot are zero, and zero coefficient rows occur at the bottom. Reduced row-echelon form additionally has unit pivots and zero entries above them.

## Mechanics: follow the current equations

The trace stores exact rational matrices, pivot columns and the operation used. Next, Previous, direct step selection and optional Play select immutable mathematical states. The input fields accept decimals with at most two places in $[-4,4]$; rejected text leaves the previous system intact. Keyboard stepping provides the same edits.

The educational model supports one to four equations and unknowns; the explorer offers 2×2, 2×3, 3×2 and 3×3 systems. It is a bounded exact solver, not an unbounded symbolic engine. Pivot selection takes the first remaining nonzero row deterministically. A zero candidate causes a swap or a skipped column, never division by zero.

## Derivation: cancellation and back substitution

Suppose the pivot row begins with $p x_1+q x_2=u$ and another row begins with $r x_1+s x_2=v$. After dividing the pivot row by nonzero $p$, subtract $r$ copies of it from the other row:

$$
0x_1+(s-rq/p)x_2=v-ru/p.
$$

The second equation now determines $x_2$ when its coefficient is nonzero. Substitute that value upward to determine $x_1$. With more variables the same reasoning proceeds from the final pivot row upward. Normalizing pivots during forward elimination is convenient here; it is not required by the definition of echelon form.

A skipped pivot column corresponds to a free variable. Setting free variables to zero produces one **particular** solution, not the entire answer set. The complete consistent set is $x=x_0+\sum_j t_jz_j$, where each $Az_j=0$ and each $t_j$ is arbitrary.

## Worked examples

The opening system is $x+y=3$, $x-y=1$. Replace $R_2$ by $R_2-R_1$ to obtain $-2y=-2$. Scale by $-1/2$, giving $y=1$, then back substitute to get $x=2$. The trace above replays these actual equations before optionally clearing above the second pivot. Verification uses the original constraints: $2+1=3$ and $2-1=1$.

For $y=1$, $2x+y=3$, the first candidate coefficient is zero. Swapping rows gives a usable pivot and solution $(1,1)$. For $y+2z=1$, $2y+4z=2$, the first column is skipped and the second row becomes $0=0$. Both $x$ and $z$ are free: $(x,y,z)=(s,1-2t,t)$. If the second RHS becomes $3$, that last row instead asserts $0=1$ and there is no solution.

## Common mistakes

A zero row is harmless only when its RHS is also zero. A zero candidate is not proof of singularity until row swapping has been considered. Multiplying a row by zero loses a constraint. Swapping columns changes variable order and is not one of the row operations used here. A free variable need not be zero.

## Numerical considerations

Every accepted decimal represents an exact rational; even a tiny nonzero pivot contributes rank. Exact fractions can grow, so manageable dimensions are an intentional bound. Numerical Gaussian elimination generally uses pivoting strategies to control roundoff, rather than the first-nonzero rule used for this exact educational trace. A displayed approximation is never the proof that a row is zero.

## Engineering and ML connections

Linear constraints appear in circuit analysis, mechanics and parameter estimation. Elimination explains why factorizations solve many such systems efficiently. Reusing a factorization across right-hand sides avoids repeating work; deriving the inverse in II.16 reuses these same row operations.
