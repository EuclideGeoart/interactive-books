## Intuition: one distance scale, two sensitivities

A narrow valley has one direction in which small movements change the gradient sharply and another in which they change it slowly. A shared learning rate must handle both. Too small a rate makes progress slow in the gentle direction; too large a rate overshoots in the steep one.

Overshooting does not automatically mean failure. A coordinate can cross its target on every step and still get closer. The useful distinction is whether its error magnitude shrinks, remains constant, or grows. A path's zigzag shape alone cannot decide that distinction, and a short initial loss decrease cannot prove long-run convergence.

## Definition: error contraction and all-start stability

For $L=a(x-c)^2/2+2y^2$ with $a>0$, the unique minimizer is $\theta^*=(c,0)$. Define error coordinates $e_x=x-c$ and $e_y=y$. Gradient descent uses $\theta_{k+1}=\theta_k-\eta\nabla L(\theta_k)$ with $\eta>0$.

A scalar error mode with curvature $\lambda>0$ obeys

$$
e_{k+1}=(1-\eta\lambda)e_k.
$$

Here the Hessian eigenvalues are $a$ and $4$, so the two multipliers are $r_x=1-\eta a$ and $r_y=1-4\eta$. In exact real arithmetic, convergence to the minimizer **from every starting point** requires

$$
\abs{r_x}<1,\qquad\abs{r_y}<1
\quad\Longleftrightarrow\quad
0<\eta<\frac{2}{\max(a,4)}.
$$

This is an all-start guarantee for this positive-curvature quadratic. An unstable or nondecaying mode whose initial error is exactly zero remains absent. Such a particular run can converge outside the all-start interval. Neither the formula nor a successful run supplies a universal rate bound for other objectives.

## Derivation: the curvature condition is a geometric-series condition

The gradient is $(a(x-c),4y)$, so direct substitution gives

$$
x_{k+1}-c=x_k-c-\eta a(x_k-c)=(1-\eta a)(x_k-c),
\qquad y_{k+1}=(1-4\eta)y_k.
$$

Unrolling each recurrence yields

$$
x_k-c=(1-\eta a)^k(x_0-c),\qquad
y_k=(1-4\eta)^ky_0.
$$

For a nonzero initial component, a power $r^k$ tends to zero exactly when $\abs r<1$. Solve $-1<1-\eta\lambda<1$: subtract 1 and divide by positive $\lambda$ to obtain $0<\eta<2/\lambda$. Both modes must satisfy this, so the larger curvature sets the shared upper boundary.

| Mode factor r | Nonzero error behavior |
| --- | --- |
| $0<r<1$ | Same-side contraction |
| $r=0$ | That component reaches its target in one step |
| $-1<r<0$ | Alternating, shrinking error |
| $r=-1$ | Alternating without decay |
| $\abs r>1$ | Growing error magnitude |

The loss follows squared factors:

$$
L_k=\frac a2r_x^{2k}(x_0-c)^2+2r_y^{2k}y_0^2.
$$

Within the strict all-start interval, each active contribution decreases. Negative factors can therefore produce decreasing loss even while coordinates alternate. At a boundary, an active contribution can remain fixed while another decreases.

## Worked examples: a drop, a boundary, and an exception

With $\eta=1/4$, the factors are $(3/4,0)$. The canonical first step is

$$
(2,1)\longmapsto(3/2,0),\qquad L:4\longmapsto9/8.
$$

The second point is $(9/8,0)$ with loss $81/128$. For every $k\geq1$, the y component is zero and $x_k=2(3/4)^k$. This is the default worked replay.

<Stage caption="Replay the canonical η=1/4 run: x errors multiply by 3/4, y reaches zero in one step, and the first losses are 4, 9/8, 81/128."><OptimizationStage chapter="rate" worked client:load /></Stage>

At $\eta=1/2$, the factors become $(1/2,-1)$. The first two next points and losses are

$$
\theta_1=(1,-1),\ L_1=5/2,\qquad
\theta_2=(1/2,1),\ L_2=17/8.
$$

Loss approaches $2$ while y alternates between $1$ and $-1$. The vector does not converge to $(0,0)$; decreasing loss has concealed a nondecaying mode.

At $\eta=3/4$, a start $(2,1)$ has $y_k=(-2)^k$, so its y error grows. A start $(2,0)$ instead has $y_k=0$ and $x_k=2(1/4)^k$, so it converges. This zero-mode exception does not refute the all-start boundary $1/2$.

For a balanced comparison inside the interval, $\eta=2/5$ gives factors $(3/5,-3/5)$. Its first point is $(6/5,-3/5)$ and loss $36/25$. Both squared contributions multiply by $9/25$ thereafter. This first loss is higher than the canonical first loss, yet its worst error factor is smaller: fastest initial improvement and fastest eventual contraction need not select the same rate.

## Common mistakes and counterexamples

The rate is not the error multiplier. Different curvatures convert the same rate into different factors. Also apply the x factor to $x-c$, not to x, when the center is shifted.

Oscillation does not imply divergence: a factor of $-1/2$ contracts, while $-1$ does not decay and $-2$ grows. A short decreasing loss trace does not imply parameter convergence, as the $\eta=1/2$ example demonstrates. A zero starting mode can also make an unstable rate appear safe until that mode is perturbed.

For a positive-curvature quadratic, 0 &lt; η &lt; 2/max(a,4) makes every mode contract. Outside that interval, a particular trajectory can still converge when each unstable or nondecaying mode has exactly zero initial error.
</Callout>

## Numerical considerations

The convergence derivation concerns exact real arithmetic. A binary64 trajectory can stagnate when a displacement rounds away, underflow to zero, overflow, or stop at a finite iteration budget. These are computational events, distinct from the behavior of $r^k$ as $k\to\infty$.

Near a boundary, a small rate or curvature perturbation can move a factor from slightly inside to slightly outside magnitude 1. Compare the unrounded state and a stated numerical error scale rather than a rounded displayed factor. An exactly absent mode is also a special case; small representation or input errors in that coordinate can matter greatly when its factor has magnitude above 1.

The references label numerical trajectories binary64 and reject non-finite states. Their finite tolerance checks verify implementation on a bounded set of runs; the tolerance is not part of the mathematical definition of stability.

## Engineering and ML connections

The [Hessian](../hessian-curvature/) describes directional curvature, and [gradient descent](../gradient-descent/) turns that curvature into repeated errors. For a positive-definite quadratic, a large ratio of largest to smallest curvature can force a shared stable rate that contracts the gentle direction slowly. Parameter scaling can therefore change how efficiently the same optimizer moves.

A neural-network objective usually lacks one constant Hessian valid across the full path, so this quadratic interval must not be presented as its global safety certificate. It is a local mechanism to inspect: changes in curvature, gradient scale, and parameter units can change a rate's behavior. The next chapter adds [momentum](../momentum/), whose extra memory changes the recurrence and requires its own analysis.
